# Arqan tartısıw: Matematika 🪢

Matematika páninen interaktiv, eki komandalıq intellektual oyın platforması.
Tolıq Qaraqalpaq tilinde tayarlanǵan hám mobil telefonlar ushın arnawlı beyimlestirilgen.

## ✨ Qásiyetleri
- **Tolıq Qaraqalpaq tilinde:** Interfeys, parametrler, ameller hám xabarnamalar tolıq Qaraqalpaqsha.
- **Milliy kiyimler hám qaharmanlar:** Qaraqalpaq milliy taqıyası, geometrik naǵıslı (shúkirek, qoshqar múyiz) milliy shapan/beshpent kiygen qaharmanlar.
- **Milliy nama:** Berik Dáwenov atqarıwındaǵı qızǵın "Aday kúyi" fon naması retinde ornatılǵan.
- **Mobil hám sensorlı ekrannıń qolaylıǵı:**
  - Vertikal (portrait) hám gorizontal (landscape) rejimlerinde tolıq qolaylı interfeys.
  - Eki oyınshı bir waqıtta sensor ekrandı basqanda qotpaytuǵın kóp sensorlı (Multi-Touch) texnologiya.
- **Matematikalıq ameller:** Qosıw, alıw, kóbeytiw, bóliw hám salıstırıw.
- **Sanlar xanası:** 1-xanalı (0–9), 2-xanalı (10–99), 3-xanalı (100–999).
- **Waqıt parametrleri:** 1, 3, 5, 10 minut yamasa sheksiz rejim.

## 🚀 Qalay iske túsiriw kerek?

### 1. Brauzerde tikkeley ashıw
`index.html` faylın qálegen brauzerde ashıń.

### 2. Lokal server arqalı (Windows)
`Oyin_Baslaw.bat` faylın basıp iske túsiriń yamasa PowerShell arqalı:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1 -port 8080
```
Brauzerde `http://localhost:8080` máziline kiriń.
